# HUNTER Digital Agency - Portfolio

Portfolio website for HUNTER Digital Agency showcasing web development, UI/UX design, and AI solutions.

## 🚀 Features

- Modern responsive design
- Smooth animations with Motion/React
- Multilingual support (Arabic/English) 🌍
- Project portfolio showcase
- Testimonials section
- Contact form
- Resume modal
- Dark mode friendly

## 💻 Tech Stack

- **Frontend**: React 19 + TypeScript
- **Styling**: Tailwind CSS 4
- **Animations**: Motion (Framer Motion)
- **Build Tool**: Vite
- **Icons**: Lucide React

## 🎯 Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The site will be available at `http://localhost:3000`

### Build for Production

```bash
npm run build
```

The optimized build will be in the `dist` folder.
